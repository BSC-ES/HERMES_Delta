About
=====

NES (NetCDF for Earth Science) is the Python I/O library used by SNES, the framework that implements the data post-processing pipelines at the Earth Sciences department, to read and write netCDF files.  [oai_citation:0‡README.md](sediment://file_00000000aa6c7246a0caf7519dd48944)

How to install
==============

Use the following command to install the library::

   pip install nes

Read the `FAQ <https://earth.bsc.es/gitlab/es/nes/-/wikis/faq>`_ if you encounter any problems. If they do not resolve your issues, please contact the developers.  [oai_citation:1‡README.md](sediment://file_00000000aa6c7246a0caf7519dd48944)

To run the library, please follow the instruction in the `wiki <https://earth.bsc.es/gitlab/es/nes/-/wikis/home>`_.  [oai_citation:2‡README.md](sediment://file_00000000aa6c7246a0caf7519dd48944)
